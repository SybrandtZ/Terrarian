# Terrarian

A guide that will give tips, general item recommandation and a checklist of what to do.

## Project Structure

- `index.html` — Core HTML layout and embedded CSS styling.
- `app.js` — Chapter data store, interactive checklist state, and DOM rendering/navigation logic.
- `tests.js` — Basic Node.js assertions to verify the project structure and default state.
- `README.md` — Project documentation.

## Getting Started on vscode.dev

1. **View the website:** Open `index.html` directly in your browser or preview it in your workspace.
2. **Edit chapters or checklists:** Update the `chapters` array inside `app.js`.
3. **Run tests:** If running in an environment with Node.js support, run:
   ```bash
   node tests.js
